# Перенос любимых треков и плейлистов Spotify

Быстрый вариант — [Exportify](https://exportify.app/),
[исходный код и описание формата](https://github.com/watsonbox/exportify).

1. Откройте Exportify, нажмите **Get Started** и войдите в Spotify самостоятельно.
2. Разрешите чтение плейлистов и библиотеки. Пароль вводится на странице Spotify.
3. Нажмите **Export All**. По документации Exportify архив включает **Liked Songs**,
   плейлисты и сохранённые альбомы; наш импортёр берёт треки и плейлисты.
4. Сохраните ZIP в `spotify-inbox/`.
5. В нативном HomeMusic выберите **Импорт из Spotify**, откройте ZIP, проверьте названия
   и количество треков, затем нажмите **Перенести музыку**.

Плейлисты сохраняют порядок и повторяющиеся треки. Любимые треки переносятся как лайки.
Уже имеющиеся файлы связываются с библиотекой, остальные сопоставляются с каталогом.
В режиме экономии музыка скачивается при прослушивании. Качество совпадения зависит
от метаданных и доступности источников; список ненайденных треков доступен в веб-интерфейсе
HomeMusic → Перенести музыку. Наличие всего аудио исходной библиотеки не гарантируется.

Можно выбрать отдельный CSV. Файл лайков должен называться `liked_songs.csv` или
`Liked Songs.csv`; остальные CSV считаются плейлистами. По одному имени CSV невозможно
надёжно отличить вручную переименованный файл лайков от обычного плейлиста.

Если Exportify не даст авторизоваться, есть независимый от его API вариант:
запросить **Account data** через [инструмент скачивания данных Spotify](https://www.spotify.com/account/privacy/).
Из полученного архива достаточно `YourLibrary.json` и `Playlist*.json`; можно выбрать
сам ZIP. [Описание официального экспорта](https://support.spotify.com/article/understanding-your-data/).
Подготовка Spotify экспорта может занять время. История прослушивания не заменяет лайки.

Здесь не нужен собственный Spotify Developer App. Его ограничения Development Mode
(включая Premium владельца приложения) относятся к другому способу подключения;
[официальное описание](https://developer.spotify.com/documentation/web-api/concepts/quota-modes).
Фактический вход в Exportify с вашим аккаунтом пока не проверялся.

Экспорт передаётся только локальному HomeMusic. Токены, пароль, сведения о платеже,
профиль и история прослушивания из архивов не импортируются. Архив не распаковывается
на диск. Ограничения: 50 МБ в распакованном виде, 512 файлов, 100 000 записей треков.
Эпизоды подкастов не импортируются. Для локальных файлов Spotify переносится только
информация о треке; сам аудиофайл нужно добавить в HomeMusic отдельно.

Это разовый перенос экспорта. Постоянная синхронизация аккаунта Spotify не настроена.
